# Agent Board v0.4.1

This release brings the reviewed compact workspace design to the Mac app and local board.

- Empty sections collapse, and empty attention subgroups are hidden.
- The sidebar starts collapsed and remembers your choice.
- The purple app icon replaces the placeholder letter in the board and browser tab.
- Star is an icon. Action explanations use one tooltip that stays within the window.
- A Releases button in the board and Check releases in the Mac menu show the running version and open the private release page.
- The newer v0.3.4 menu status colors, stable polling, and session-opening fixes remain included.

Done, Continue later, Temporary, Dismiss, and workstream completion remain manual choices. Idle activity is never treated as completion.

The Mac build targets Apple Silicon and macOS 13 or later. It is locally signed and not notarized. The release page is a manual check; the app does not download or install updates automatically.
