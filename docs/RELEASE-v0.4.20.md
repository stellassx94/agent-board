# Agent Board v0.4.20

This release builds on v0.4.19. It lets the board set up its own Claude Code hooks, so you do not have to edit `settings.json` by hand.

- **The board offers to add its Claude Code hooks.** Claude Code does not write its permission prompts to the chat log, so without a hook a chat that waits for you to allow a tool stays in **Working** and never reaches **Asking you**. Until now you had to add that hook, and the resume-link and completion-suggestion hooks, to `settings.json` yourself. When Claude Code is installed and any of these hooks is absent, the board now shows a one-time **Finish setup for Claude Code** box that names what is missing. **Add hooks**, after a second confirming click, adds the four hooks: permission prompts, instant resume links, resume links at the end of a turn, and completion suggestions.
- **The setup is careful with your settings.** Before it writes, the board saves a copy of `settings.json` in the `backups` folder of the Agent Board data folder. It adds only its own hook entries, replaces older Agent Board hook entries that point at another copy of the scripts, and changes no other setting. It refuses a `settings.json` that it cannot read as JSON. Each hook command ends in `|| true`, so a moved or removed app cannot interrupt Claude Code. **Not now** hides the box. The board never edits `settings.json` unless you choose **Add hooks**.
- All other board behavior is unchanged. See [Security notes](SECURITY_NOTES.md) for the new local request that performs the setup.

The Apple Silicon macOS ZIP is `Agent-Board-v0.4.20-macos-arm64.zip` (SHA-256 `a0cc3d19bcc347968658cd5a5e0c46ad073d04909aff2b092acd44fc7a6a33ba`). The VS Code extension is unchanged; keep `agent-board-sidebar-0.3.4.vsix` from v0.4.19. The app targets macOS 13 or later, is ad-hoc signed and not notarized, and may require **Open Anyway**. The digests and packages come from the same release account, not independent publisher authentication; see [Security notes](SECURITY_NOTES.md). Publishing does not update an already-running local app; use **Check for updates…** in v0.4.9 or later.
