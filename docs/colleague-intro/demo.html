Stays localNothing leaves your Mac

The board reads your own session history on this Mac and serves it at http://127.0.0.1:8765/.

Required before first use: System Settings → Privacy & Security → Accessibility → add Agent Board and switch it on. If it is already running, quit and reopen it. This pilot build is locally signed and not notarized.
