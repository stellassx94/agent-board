I’m piloting Agent Board, a local Mac menu bar and workstream view for Claude Code and Codex sessions. It helps you spot what is working, what needs you, and what to continue later. Your board reads your own Mac’s session history.

The project and download are public, with no corporate VPN required. Download the ready-built Apple Silicon app from https://github.com/stellassx94/agent-board/releases/tag/v0.4.11 or build it yourself from https://github.com/stellassx94/agent-board.git. Before first use, allow Agent Board under System Settings → Privacy & Security → Accessibility; if it is already running, quit and reopen it. The attached QUICKSTART.md explains both options and the separate Open Anyway step for this non-notarized build.
