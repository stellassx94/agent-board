# Agent Board v0.4.16

This release builds on v0.4.15. It shows Claude permission prompts exactly, and it stops the VS Code sidebar from changing the installed app.

- **Claude permission prompts show as Asking you, from a hook.** Claude Code does not write its permission prompts to the chat log. A new optional Claude Code `Notification` hook, `agent_board_classify.py capture-prompt` with the matcher `permission_prompt`, records each prompt in `agent_board_prompts.json`. When the prompt is newer than the chat's latest activity and a tool is still pending, the board shows the chat under **Asking you** with "Waiting for your permission". The state clears when the chat logs new activity or the approved Bash command starts. A prompt from a subagent clears when the subagent continues. The hook ignores other notifications, keeps entries for 7 days, and never interrupts Claude. See the README for the hook command.
- **The 10-second approval guess from v0.4.15 is removed.** A Claude Bash command that has not started now stays in **Working** unless the hook reports a prompt. Codex approval detection is unchanged.
- **The VS Code sidebar no longer runs the app's Python files.** When the board is not running, the sidebar now opens the installed app in the background, and the app starts its own service. Before, the sidebar ran the bundled `agent_board.py` with Python. That wrote `__pycache__` folders into the signed app, which broke its signature check, and left a service copy that the app updater could not stop. If a service from an older app version still holds the board port, the sidebar stops it only when it runs from inside the installed app, and the app then starts the current one. A custom `agentBoard.scriptPath` still runs that script, now without writing cache files.
- Regression tests cover the hook capture, the permission state, its clearing rules, and the subagent case. All other board behavior is unchanged.

The Apple Silicon macOS ZIP is `Agent-Board-v0.4.16-macos-arm64.zip` (SHA-256 `988554fc0e97c928d0a3e9dfdf50cf5f477dadad512b5cb5fe711b1e57044bce`). The VS Code extension is updated to `agent-board-sidebar-0.3.2.vsix` (SHA-256 `9c562b06e5716bcdacef0e6780af92c31517f895a65fea2fd3e7abd88ce3bf83`); its source is in `vscode-extension/`. The app targets macOS 13 or later, is ad-hoc signed and not notarized, and may require **Open Anyway**. The digests and packages come from the same release account, not independent publisher authentication; see [Security notes](SECURITY_NOTES.md). Publishing does not update an already-running local app; use **Check for updates…** in v0.4.9 or later. The updater does not install the optional hook; add it once yourself.
