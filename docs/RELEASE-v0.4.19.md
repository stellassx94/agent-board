# Agent Board v0.4.19

This release builds on v0.4.18. It makes the VS Code sidebar show the same rows and counts as the board.

- **The VS Code sidebar shows one row per workstream.** Before, the sidebar listed every session, while the board's default view lists workstreams. A resumed chat that was already linked to its original session still appeared as a second row with the same title, and the sidebar counts were higher than the board's. The sidebar now reads the same workstreams as the board. A row with linked chats shows `N chats`. Clicking a row, or **Resume in new chat**, acts on the latest chat in the workstream. **Mark done** marks the whole workstream done, and **Continue later** acts on its lead chat, the same targets the board's own buttons use. The badge counts workstreams. With a board service older than the Workstreams view, the sidebar still lists sessions.
- **A resumed chat can join its workstream while it is still working.** The new optional `agent_board_workstreams.py capture-tool` hook records the resume link as soon as the resume marker command runs. Add it as a Claude Code `PostToolUse` hook with the matcher `Bash`. The existing `capture-stop` hook records the same link when the turn ends and still works without it. An existing link is never replaced.
- All other board behavior is unchanged.
